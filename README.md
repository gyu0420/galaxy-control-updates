ZIP을 풀고 `Galaxy_Control_v8_41.vbs`를 실행하세요. Windows와 Python 3.10 이상이 필요하며, 최초 설치 시 필요한 구성 요소를 자동으로 설치합니다. 처음 실행할 때 바탕화면 바로가기를 만들고, 컴퓨터 시작 시 자동 실행 여부를 선택할 수 있습니다.

이번 버전에서는 오늘 공연 없음·다음 공연 카운트다운·진행 중·마지막 공연 종료 안내를 제공합니다. 저장된 전체 시간표와 특별 공연·휴연 설정을 사용하므로 예매 마감만으로 공연이 없다고 판단하지 않습니다. 한국시간은 UTC+9로 계산하며 별도 시간대 패키지 없이 작동합니다.

세 브랜드 방문자 리뷰는 30분마다 확인합니다. 새 리뷰는 빨간 배경의 흰색 `n`으로 표시하고, 리뷰 화면을 열면 해제합니다. 업데이트 내용은 설치 전에 표시하며, `확인`을 눌러야 다운로드와 재실행을 진행합니다.

`latest.json`과 `updates/8.41.zip`은 기존 앱의 서명 검증 방식과 호환됩니다. 공개 설치본에는 직원 무전 방 코드나 개인 설정을 포함하지 않습니다.
